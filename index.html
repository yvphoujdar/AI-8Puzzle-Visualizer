What is the 8-Puzzle?

The 8-puzzle is a small sliding puzzle. It has a 3×3 board with eight numbered tiles and one empty square (the blank). A tile next to the blank can slide into it. The aim is to slide tiles until the board matches a given goal arrangement.

It is a classic example in AI because it is easy to understand but still needs a proper search to solve. We can describe it as a state-space search problem:

  • State: where each of the 8 tiles and the blank are on the board.
  • Initial state: the board we start with.
  • Actions: move the blank Up, Down, Left or Right (only if it stays on the board). So each state has 2, 3 or 4 next states.
  • Goal test: does the board match the goal board?
  • Path cost: normally each move costs 1, so the cost is the number of moves. This site also lets you make a move cost the number on the tile you slide, which shows where Uniform Cost Search really matters.

There are 9! = 362,880 ways to arrange the board, but only half of them (181,440) can be reached from any given start. A quick check tells us if a puzzle can be solved: count the pairs of tiles that are in the wrong order (the inversions). A move never changes whether this count is even or odd, so the start and goal must have the same “evenness”. The hardest puzzles need 31 moves.
